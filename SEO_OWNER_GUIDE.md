# SEO: инструкция для владельца FixLine

Всё, что здесь описано, делается один раз (кроме еженедельного чеклиста). Код со стороны сайта уже готов и задеплоен.

---

## 1. Google Search Console (обязательно, ~15 минут)

Зачем: без GSC вы не видите, по каким запросам показывается сайт, и не можете попросить Google переиндексировать страницы.

1. Зайдите на https://search.google.com/search-console под Google-аккаунтом.
2. «Добавить ресурс» → тип **«Доменный ресурс»** → введите `fixline.com.ua`.
3. Google попросит DNS-запись TXT. Домен обслуживается там, где вы его покупали — в панели DNS добавьте запись:
   - Тип: `TXT`, Имя/Host: `@`, Значение: строка вида `google-site-verification=...` (её покажет GSC).
   - Подтверждение может занять от минут до пары часов.
4. После подтверждения: слева меню **«Файлы Sitemap»** → добавьте `https://fixline.com.ua/sitemap.xml` → «Отправить».
5. Проверьте через 2–3 дня раздел **«Индексирование → Страницы»**: должно расти число проиндексированных.

**Ускорение переиндексации после наших изменений:** в GSC вверху есть строка «Проверка URL» — вставьте туда 5–10 ключевых страниц (главная, /shop, топ-категории, топ-товары вроде CT 17) и для каждой нажмите «Запросить индексирование».

## 2. Google Business Profile (локальное преимущество в Харькове, ~20 минут)

Зачем: карточка компании в Google Картах и локальной выдаче «рядом со мной». Национальной выдаче не мешает, харьковскую усиливает.

1. https://business.google.com → «Добавить компанию».
2. Название: FixLine (как на сайте). Категория: «Магазин стройматериалов» / «Строительный магазин».
3. Укажите реальный адрес в Харькове, телефон, часы работы, сайт fixline.com.ua.
4. Подтверждение — обычно открытка на адрес или по телефону/видео.
5. После подтверждения: добавьте 5–10 фото (склад, товары, упаковка заказов), заполните описание.
6. Просите довольных клиентов оставлять отзывы в Google — это главный фактор локального ранжирования.

## 3. Google Merchant Center (самый быстрый национальный канал, ~30 минут)

Зачем: бесплатные товарные листинги в Google Покупках работают по всей Украине сразу, независимо от органических позиций сайта. Фид уже готов и отдаёт ~743 товара с ценами.

1. https://merchants.google.com → создайте аккаунт (страна: Украина, валюта: UAH).
2. Подтвердите сайт: проще всего через уже подтверждённый Search Console (Merchant предложит этот вариант сам).
3. **Товары → Фиды → Добавить фид**:
   - Страна продажи: Украина, язык: украинский.
   - Способ: «По расписанию» (Scheduled fetch).
   - URL фида: `https://fixline.com.ua/api/google-merchant-feed?key=ВАШ_КЛЮЧ`
     (значение ключа — переменная `FEED_SECRET_KEY` из настроек Vercel; спросите у Claude «покажи как посмотреть FEED_SECRET_KEY» или найдите в Vercel → Settings → Environment Variables).
   - Частота: ежедневно, ночью.
4. Заполните обязательные данные магазина: **Доставка** (Нова Пошта, укажите тариф или «зависит от перевозчика»), **Возвраты** (14 дней), контакты.
5. Включите **«Бесплатные списки товаров»** (Free listings) в разделе «Развитие → Управление программами».
6. Через 3–5 дней проверьте «Товары → Диагностика»: цель — 0 ошибок. Предупреждения (warnings) допустимы.

## 4. Еженедельный чеклист (10 минут в неделю)

В Google Search Console:
- **«Эффективность»**: сортируйте запросы по показам. Запросы с позицией 11–30 (2–3 страница) — главные кандидаты «дожать»: сообщайте их Claude, под них усиливаем контент конкретных страниц.
- **«Индексирование → Страницы»**: число проиндексированных должно расти, «исключённых» — не расти резко.
- CTR по брендовым запросам (fixline) — должен быть высоким (>20%).

В Merchant Center (если подключили):
- «Диагностика»: новые ошибки фида → сообщить Claude.

Раз в месяц:
- Проверить позиции руками (в режиме инкогнито): «грунтовка церезит ст 17 купить», «краска аура фасад купить», «купить герметик» + 2–3 своих ключевых запроса. Записывать страницу выдачи, динамику.

## 5. Ссылки (фоновая задача, самый долгий фактор)

Для молодого домена внешние ссылки — критичный фактор национального топа:
- Дубль каталога на Prom.ua со ссылкой на сайт (уже в планах — фид Prom готов).
- Регистрация в украинских строительных каталогах и справочниках (обычно бесплатно).
- Попросить поставщиков/партнёров (дистрибьюторы Ceresit, Aura и т.д.) добавить FixLine в список «где купить».
- Отзывы клиентов на страницах товаров сайта — даёт и контент, и звёздочки в выдаче (разметка уже стоит).
